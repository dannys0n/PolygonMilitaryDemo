# Unpolished animation review

Production weapons, rigs, controllers and clips live in the normal game asset folders. This directory contains only review catalogs for unpolished equipment. `OriginalProportionsCatalog` supplies `Armory_UE4OriginalProportions`; the ordinary `Armory` reads the production catalog's polished entries.

The three downloaded animation sources remain under `Assets/Imported/FPSAnimationTests` (`animated-shotgun`, `fps-benelli-m4-animations`, and `animated-magnum`). The FPS Animation Pack source library remains under `Assets/FPSAnimationPack`.

Obsolete generated conversion proofs and duplicate animation-test prefabs have been removed. Edit accepted weapons in their production definitions and prefabs. Armory selection reads these assets directly.
